Library Book Management System

Project Description

A simple Library Book Management System developed using Python.

Project Features

- Welcome message.
- Add new books to the library.
- Display all available books.
- Search for a book by name.
- Borrow books from the library.
- Exit the system.

Programming Language

Python

Tools Used

- Python
- GitHub

How to Run

1. Download the project.
2. Open the main.py file.
3. Run the program using Python.
4. Choose an option from the menu.

Project Purpose

The purpose of this project is to practice Python programming, user input, conditions, loops, and lists.
